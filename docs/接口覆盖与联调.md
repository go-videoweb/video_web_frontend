# 接口覆盖与联调

当前适配来源：后端 `ba2604fd`。网关源 OpenAPI、有修正的有效契约、生成类型和 49 项 HTTP 操作见 [契约说明](../contracts/README.md) 与 [操作清单](../contracts/operations.json)。端到端验收须连接匹配的网关、用户与视频服务；演示不替代联调。

错误策略另已同步后端 `f6cfcc39`，集中定义在 [error-codes.ts](../src/lib/api/error-codes.ts)。本次未改变路由和 OpenAPI，保留原快照来源，不伪造契约重新生成记录。

| B02 关注          | 关注页建组/改名/设默认/批删和分页；个人页关注、移动、取消；组内关注删除前明确提示                         |

## 契约细节

- 生成脚本规范化换行，并将有效契约的 query 名调整为 proto snake_case（包括点号游标）。路径参数占位名、请求体和响应仍遵循各自协议。
- HTTP 200 可能是业务错误。ApiError 保留 code/reason/metadata；刷新只限 3005 + 新 access token 的明确鉴权响应。不要根据描述文案判断权限。
- 新身份码 3124、3127、3128、3129 与原鉴权码统一使会话失效。3123 是普通参数错误，即使 reason 同样是 INVALID_USER_ID 也不清会话；不能按 31xx/41xx/52xx 数值区间判断登录状态。真实 HTTP 401/403 及旧业务体 401/403 兼容处理保留。
- 注册部分成功、密码会话撤销失败、验证码限流、收藏冲突的 reason/metadata 契约未变。模拟响应改用实际业务码和 HTTP 200；媒体缺失等传输错误仍可使用实际 HTTP 状态。
- 图形验证码适配保留，仍不将其当成已绑定登录验证的 UI。媒体读取仍使用同目录 MPD/分片与公开封面路径。
- 缓存按身份分隔。视频点赞结果未知或收藏关系冲突时，不自动重发。详情回读有业务副作用，只在明确请求时核对。
- 未完成或失败视频是否从发现列表隐藏由后端决定；旧账号默认组、投稿发布者身份、无 ID 的创建结果恢复、生产验证码代理来源和分享域名仍须确认。

## 联调顺序

1. 退出演示，确保 API proxy、分类与后端版本匹配。准备隔离账号、已授权小视频和邮箱。
2. 验证注册可立即访问登录接口、头像重新加载、真实邮件收件和用途隔离。分别测注册/改密部分成功错误，确认不会被提示重复提交。
3. 收藏测试空页、私密拒绝、他人公开、过期记录 ID。关注测试旧账号、默认组不可删、批删后关系与计数。
4. 检查大 ID、零秒、同秒续页、纳秒评论时间、引用失效及点赞取消后回读。登录和游客的详情缓存不能互串。
5. 上传封面后刷新，继续原片，断开请求后查询已知 ID；分别验证 processing、completed、failed、非本人读取、网络中断。
6. 用实际公网返回的分享地址打开新窗口验证游客播放及部署路由。记录 HTTP 错误体、状态和版本，不记录密码、验证码或令牌。
