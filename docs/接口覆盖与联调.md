# 接口覆盖与联调

更新：2026-10-18。契约来源 `b87a6830`；共 38 个 HTTP 操作。**本轮没有连接真实 Go 网关，所有操作的真实联调状态均为“未验证”。**

## 状态定义

- 页面接入：用户能从已实现页面发起该操作，仍需真实联调。
- 媒体链路：由 img/video/dash.js 请求，不是单独按钮。
- 仅适配：已有函数，当前没有用户操作入口或安全流程未绑定。
- 受阻适配：已有边界位置，但缺少后端 ID、读取或状态契约，不做假 UI。

“已模拟”仅表示存在 MSW handler，不表示该操作的全部成功/失败分支都已测试。具体自动化场景见 [验证记录](验证记录.md)。没有按页面接入率虚报“38 项业务完成”。

## 已知服务端缺口

收藏查询/创建 ID、关注列表发现/目标 ID、详情个人互动状态、弹幕读取、头像安全 URL、投稿处理状态、匿名密码恢复、分享公共地址尚未闭环。完整历史分析保留在工作区根目录《后端功能闭环缺口清单.md》；本文件可独立随前端仓库交付，不能靠该外部文档才能理解功能边界。

前端不能替代服务端所有权鉴权。真实账户接入前要核对 userId/视频/收藏归属，不因为页面隐藏了字段就视为权限安全。

## 联调顺序

1. 使用隔离账号，确认当前后端 commit 与契约，不自动替换配置或迁移数据库。
2. 退出演示；配置 API_PROXY_TARGET，分类对齐数据库，重启 Vite。
3. 登录检查 userId 字符串与双 token；不复制凭据到文档或截图。
4. 列表/详情检查 ProtoJSON 字段、省略零值与时间；确认游客策略。
5. 用已授权小视频检查公开封面、MPD MIME、相对 m4s、实际播放与媒体失败。
6. 测试评论/回复/点赞、分享和贝壳，检查数据库/DTM 实际结果，未知结果不盲重试。
7. 分步投稿并查后台 ffmpeg 结果，HTTP 接受只能标记已提交。确认头像返回是否可浏览器读取。
8. 最后验证退出、过期刷新、缓存清理、账号切换与失败分支。
