更新日期：2026-10-18。

## 当前状态

前端工程已建立，12 章均已补充实际文件地图、关键流程、设计约束、自检与可选练习。源码链接已按当前目录核对；本轮真实执行的检查集中记录在 ../验证记录.md。练习供以后按需学习，不是本次交付的前置任务。

## 阅读方式

本文只承担总导航、章节关系和进度说明。知识讲解放在独立章节，公共概念集中在基础章节，业务章链接引用，减少重复。

不要求开工前读完，也不将练习作为功能交付的前置条件。可以先使用项目，再从感兴趣的功能进入；遇到基础概念时跳回相关章节。

- 快速了解：阅读本章目标、用户操作、流程和文件地图。
- 理解实现：继续阅读必要知识、设计解释与关键代码。
- 尝试修改：完成局部练习，运行与改动有关的验证。

## 建议阅读路径

- 初次接触项目：01 -> 03 -> 04 -> 05；语法疑问按需查 02。
- 关心后端如何被展示：04 -> 06 -> 07 -> 08 -> 09。
- 准备亲自改代码：03 -> 对应业务章 -> 11 -> 12。
- 收藏、关注、弹幕等受后端能力影响的内容：先看实际交付状态，再读对应章节，不把待接入能力当作已实现。

## 每章如何展开

详细章节统一采用[章节模板](章节模板.md)，包含目标、功能体验、必要知识、代码地图、完整流程、设计解释、关键代码、动手验证、误区和自检。章节讲解以实际源码为准；练习与真实后端/集群验证分别标注，不将建议操作冒充已执行。

章节过长时按主题建立同名子目录，将案例和专题另存为 Markdown；本章保留导航与连贯主线。保持编号和链接稳定，不机械按每个组件拆成一个文件。

## 文档维护约定

- 章节进度使用“章节提纲”“项目讲解已补充”“代码与命令已核对”，学习进度由读者自行决定。
- 明确区分原生 JavaScript/浏览器、React、第三方库和本项目约定。
- 文件地图标注阅读目的；源码路径、行号和命令只在实际存在并核对后添加。
- 关键函数解释输入、输出、约束与副作用，不逐行重复语法。
- 练习提供修改范围、观察结果和验证办法，可选提示与参考解答分开放置。
- 代码行为变化时同步更新讲解；未运行的验证、尚未支持的后端能力明确注明。
- 教材已迁入前端仓库 docs/学习路线/。根工作区原入口保留跳转，不维护第二份正文。
