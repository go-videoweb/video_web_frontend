## 数据的实际流动

category/page 来自 useSearch，不额外保留一份 state。点击分类导航到该 category 的第一页；下一页改变 URL，再由 Query 用新的 key 获取。浏览器前进/后退因此自然恢复筛选。

页尺寸是 12。后端按 class IN、hot DESC 返回摘要，前端不改成客户端全量排序，更不能请求空分类再宣称“全部”。若真实数据库没有“科技”分类，应该修改配置，而不是伪造非空列表。

## 没有总数如何分页

服务端没有列表总数，因此不显示“共多少条/多少页”。第一页不能上一页；返回少于 12 项时下一页禁用；正好 12 项仍允许继续，下一页可能空。空页可以返回上一页，不把它解释成接口失败。

Query 数据来自服务端；Skeleton 只是加载占位，没有虚构标题/观看数。登录门槛也不是网络异常：未登录显示正常入口，接口错误显示明确重试。

## 摘要适配

后端列表外层字段为 VideoSummary，内部是 videoId、createdTime 等 ProtoJSON 字段。不要为了命名一致改服务端字段。Zod 的 default 处理省略零值；videoId 缺失不能用数组索引代替。

createdTime 为 RFC3339，展示时按浏览器时区格式化；不直接把 SQL 时间字符串当 UTC。观看数与弹幕数可能为大整数字符串，formatCount 使用 BigInt，避免精度丢失。

卡片封面走公开 API，img loading=lazy，aspect-ratio 固定；加载失败显示回退，不因图片坏掉让标题跳动。卡片链接禁用详情预取，避免 hover 增加播放量。

## 演示与真实

演示提供 24 条样例，其中科技有 14 条，方便覆盖 12+2 分页；全部样例播放同一段已授权 Sintel 测试流。不是后端真实内容，也不是推荐算法结果。真实模式没有这些固定卡片。

## 可选练习

只改卡片的时间显示顺序，不动 api/pageSize。运行 typecheck 与 browser 的发现页测试；在 360/768/1440 宽度观察长标题和图片失败回退。进一步练习：给 formatDate 增加无效时间测试，先明确希望的回退文案。
