## 两条独立链路

```text
业务：GET /video/{id}/info -> 标题/作者/简介/计数 -> 页面
媒体：GET /0/video/{id}/dash/mpd -> 相对 init/chunk.m4s -> video
```

详情匿名可读，不代表列表/评论也匿名可读。MPD 和分片是公开媒体，不用把 token 放进 URL；用户身份不取自路径中的 0。保留这个段是兼容现有后端路由，不是资源所有者 ID。

MPD 描述轨道和时间线，m4s 存编码数据；不能把一个 mp4 地址改后缀就成为 DASH。dash.js 负责解析、缓冲、调度，浏览器 HTML video 执行解码/展示。速度、音量、全屏主要使用原生 controls，不手写媒体引擎。

## 生命周期是重点

Player 的 ref 指向真实 video DOM。Effect 动态加载库，创建引擎，注册错误，initialize；返回的清理函数 reset。disposed 处理“库还没加载完，页面已离开”的竞态，避免晚到的 Promise 又创建播放器。

观看页用 key=videoId 区分资源，切换视频会释放旧实例。重试只重建媒体引擎，不自动重新读取详情；否则用户修复播放可能又增加一次播放计数。外层 Query 禁用自动读取与 hover 预取。

onTime 用 useCallback 保持稳定，时间写入 ref，不因每次 timeupdate 重绘整页。发送弹幕时才将秒转换为 hh:mm:ss。这个回调不代表弹幕读取/展示已实现。

## 如何排查

1. 标题也没有：检查业务 JSON、身份、404 与 schema。
2. 标题有但无画面：先看 MPD 是否 200 且为 application/dash+xml。
3. MPD 有但分片 404：看相对 URL、部署路径和文件名，不能回退旧 /segments。
4. 分片有但解码失败：看编码、MSE 支持、浏览器错误，而不是改 CSS。
5. 有声音没画面/黑屏：检查视频轨道与像素，不只看 network 成功。
6. 手机视口测试通过：仍需真机 Safari/iOS 媒体测试。

原文件下载另外走带头的 fetch，限制 256 MB；不能用普通 a href 绕过鉴权。大小限制避免失控内存，不等于高效大文件下载方案。

## 可选练习

在演示里播放并暂停，选择 1.5 倍速、拖到第 8 秒，Network 中找到相对分片。阅读测试里的 canvas：将当前视频缩到 64×36，再统计非黑像素。这比只断言有 video 标签更能证明画面存在，但不是画质评分。

验证命令：pnpm test:e2e --project=desktop --grep "DASH"。不要拿私人媒体执行截图测试。画质菜单只有存在多个真实轨道才有意义，目前测试流不假造清晰度。
