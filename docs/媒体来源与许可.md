# 媒体来源与许可

本地演示不使用用户的后端上传资源或私人媒体。所有卡片均是明确标记的演示内容，不表示对应创作者上传了这些照片或视频。

## Sintel 测试流

- 作品：Sintel（Blender Foundation / Blender Institute，2010），导演 Colin Levy。
- 来源：[W3C 托管的 Sintel trailer](https://media.w3.org/2010/05/sintel/trailer.mp4)。
- 作品与许可：[Sintel 署名要求](https://durian.blender.org/sharing/)、[Creative Commons Attribution 3.0](https://creativecommons.org/licenses/by/3.0/)。署名：© copyright Blender Foundation | durian.blender.org。
- 原预告片保存在 public/assets/sintel-trailer.mp4，仅用于本地播放与下载测试。
- public/assets/demo-dash/ 是前 18 秒缩放到 960 像素宽并转码成 H.264/AAC 的 DASH 测试派生流。不是原作新增内容，也不是每张演示卡片独立的视频。

播放器没有伪造画面：浏览器实际请求 MPD 与 m4s，测试检查非黑像素、时间推进与 seek。封面照片是单独的界面素材，与 Sintel 内容不对应。
