## 单元与组件覆盖

- 双 Bearer、大整数 ID、HTTP 200 业务错误、嵌套 resp/common 错误、验证码 code 不误判。
- 明确 token 刷新最多重发一次、无新 token 不重发、并发排队使用新 token、退出旧响应不能恢复会话、排队取消不发请求。
- 身份错误与非 JSON HTTP 401 清会话；网络失败不自动重发写操作。
- 下载错误 JSON 不保存成视频，超限响应提前拒绝。
- ID/计数精度、零值省略、时间/安全跳转/媒体路径处理。
- 登录空值不请求、业务失败保留输入、成功保留大 userId 并返回首页。
- 旧头像失败后新头像地址仍可重新显示。

- 没有真实 Go 网关/Consul/Redis/MySQL/MongoDB/DTM/SMTP/ffmpeg 集成验证，不能证明真实发布、互动事务或邮件成功。

- 投稿创建成功响应丢失时无法可靠找回 ID；已接受后的转码失败不能靠当前 HTTP 响应判断。前端不虚构进度或自动重建。
