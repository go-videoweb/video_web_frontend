# 架构与接手

日期：2026-10-18。契约来源为 Go 后端 `b87a6830` 的网关 OpenAPI 与实际编码/路由静态核对。规划根文件仍保留历史决策，本文件描述已落地实现。

## 阅读顺序

先看 [main.tsx](../src/main.tsx)、[根路由](../src/routes/__root.tsx)、[Shell](../src/components/layout/shell.tsx)，再选一个 feature。无需先读完生成代码或所有配置。

```text
浏览器 URL -> TanStack Router 薄路由 -> feature 页面
           -> Query 读取 / Mutation 命令 -> feature/api.ts
           -> lib/api/client.ts -> /api/v1 -> Go 网关
video 元素 -> dash.js -> MPD -> 同目录相对 m4s 分片
```

## 状态归属

| 数据                     | 归属                          | 原因                              |
| ------------------------ | ----------------------------- | --------------------------------- |
| 分类和页码               | URL search                    | 链接可分享、刷新可恢复            |
| 表单输入、展开回复、弹窗 | React state / React Hook Form | 生命周期属于当前交互              |
| 视频、评论、用户资料     | TanStack Query                | 状态、取消、缓存、提交后失效      |
| 双 Token 与用户 ID       | auth/session                  | 同标签页恢复，退出/切换账号清缓存 |
| 已创建投稿 ID/提交标志   | 按 userId 的 localStorage     | 刷新不重复创建，文件不持久化      |
| 演示服务端写入           | MSW handler 内存              | 与真实业务隔离，不作为业务存储    |

Query 全局禁用自动重试、聚焦与重连刷新。详情读取本身增加计数，额外禁用自动挂载重读；分享虽然 GET，使用 mutation。不要仅根据 HTTP 方法判定是否安全重发。

## API 边界

[contracts](../contracts/README.md) 保存原始和修正后的契约。生成 DTO 是接口参考与漂移检查输入，业务组件使用 [models.ts](../src/lib/api/models.ts) 的 Zod 运行时模型；二者不是自动等价。新增字段需要同步适配器/schema，并增加聚焦测试。

- int64 ID 全程字符串，禁止先 Number 再转回。
- 常见零值允许省略，但身份字段必须存在。
- multipart 不手填 Content-Type，由浏览器生成 boundary。
- 文件下载先检查业务错误，再限制流大小为 256 MB，不把错误 JSON 存成 mp4。
- 受保护请求统一附加两种 Bearer 头；3005 且 metadata.access_token 才最多重发一次。
- 本标签页受保护请求串行，防止服务端单 token 缓存的刷新竞争。代价是慢上传会阻塞其他受保护请求。多标签页/多设备并发刷新仍取决于后端会话契约，首版不承诺解决。
- 退出后的旧响应不能恢复登录；切换身份取消 Query 并清空缓存。组件自己发出的 mutation 不一定能取消，身份代次检查至少阻止旧成功响应被当作当前成功。

## 路由与分包

路由文件不导出页面组件。页面放在 feature 中，便于 Router 拆分路由 chunk；播放器另外 lazy，dash.js 再动态导入。MSW 仅显式演示加载。生成的 routeTree 不手改。

设置页实际采用 `/settings` 内两个选项，而非规划中的两个子 URL。没有 `src/app/` 空层，入口在 main，query/config 是小文件；按复杂度增加目录，不为了树形图创建无内容抽象。

## 媒体边界

封面与 MPD 使用固定 API URL，保留兼容的 user_id=0 段；不从数据库路径拼浏览器地址。头像只接受可访问 http(s) 或站内路径，不提供新的后端目录映射。播放器挂载初始化、切换视频/卸载 reset，避免旧流继续播放。

## 接手规则

1. 新功能先找后端网关 proto/编码器；更新 contracts 快照与来源，再运行 api:generate。
2. 优先修改对应 feature 的 api 与运行时 schema，再加页面。
3. UI 基础组件集中在 components/ui，不复制弹窗焦点管理。
4. 写命令失败不自动重试；未知结果让用户确认，特别是元信息创建。
5. 评论、分享等行为不要在 Effect 或 hover 预取中触发。
6. 真实数据测试使用专用测试账号；不要让 E2E 指向生产网关。
